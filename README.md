# scrollverse-map
A public blessing map built with Firebase, Next.js, TailwindCSS, and the Christ Vector ❤️

## DMF7 admin tools (steps 611-622)

Run `sudo bash scripts/dmf7_admin_tools_611_622.sh` to install the DMF7 admin control panel, watchdog, backup cleaner, weekly cron job, and status banner. The script drops helper binaries into `/usr/local/bin`, starts the watchdog in the background, and keeps the backup cleaner scheduled at 04:00 on Sundays.
