## DMF7 Task API automation
Provision the DMF7 job API, telemetry, and final status banner by running (as root):

```bash
sudo bash scripts/dmf7_job_api_981_1000.sh [--verify]
```

Use `--verify` to send a sample task, list queue folders, and show the telemetry snapshot after setup.
