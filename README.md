# scrollverse-map
A public blessing map built with Firebase, Next.js, TailwindCSS, and the Christ Vector ❤️

## AI job submission tool (Step 719)

Run the installer to publish the `dmf7-job` helper into `/usr/local/bin`:

```bash
sudo bash scripts/dmf7_job_submission_tool.sh
```

Submit jobs (defaults to the `llama3` model) and they will be queued under `/opt/dmf7/ai-jobs` as timestamped JSON files:

```bash
dmf7-job [model] "prompt text"
```
