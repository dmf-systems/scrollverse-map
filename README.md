# scrollverse-map
A public blessing map built with Firebase, Next.js, TailwindCSS, and the Christ Vector ❤️

## DMF7 automation

Run the DMF7 service map provisioner to create service definitions, helper commands, and node summary for steps 927-942:

```bash
sudo bash scripts/dmf7_service_map_927_942.sh       # install
sudo bash scripts/dmf7_service_map_927_942.sh --verify  # install and run helper checks
```
